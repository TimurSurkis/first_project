# Text Editor

Десктопный текстовый редактор с упором на удобную работу с Markdown, обычным текстом и базовым кодом.

## 1. О проекте

Приложение создаётся для комфортного написания заметок, редактирования документов в формате Markdown, работы с plain-text файлами и базового просмотра/редактирования фрагментов исходного кода.

### Основные технологические решения:

- **Electron**: кроссплатформенная десктопная среда.
- **React 19 + Vite**: современный компонентный UI и быстрая сборка.
- **CodeMirror 6** (`@uiw/react-codemirror`): модульное и расширяемое ядро редактора кода и текста.
- **react-icons (набор Lucide)**: иконки интерфейса.
- **mammoth и turndown**: импорт `.docx` и преобразование в Markdown.
- **IPC & Context Isolation**: безопасное взаимодействие между процессами Electron (`main`, `preload`, `renderer`).
- **i18n**: интерфейс на русском и английском языках, словари в `locales/`.

## 2. Текущее состояние и возможности

Текущие возможности приложения:

- **Базовый UX редактора**
    - **Перенос длинных строк**: включение `EditorView.lineWrapping` в CodeMirror.
    - **Темы оформления**: внедрение светлой и тёмной тем для интерфейса и редактора с возможностью переключения.
    - **Статусная строка**: отображение текущей позиции курсора (Ln, Col), подсчёт символов и слов, индикатор типа файла и кодировки.
    - **Настройки** (кнопка «Настройки» в боковой панели): язык интерфейса (русский или английский), тема (светлая или тёмная), цвет акцента (синий, зелёный, оранжевый, серо-синий), перенос длинных строк, размер шрифта (12–32 px) и размер табуляции (2, 4 или 8 пробелов). Значения сохраняются между запусками.
    - **Выпадающие списки** (`Dropdown`) собственные, одинаковые во всём интерфейсе. Поддерживается навигация клавишами: `↑`/`↓`, `Home`/`End`, `Enter` для выбора, `Escape` для закрытия. Ширина подстраивается под содержимое, у списка заголовков ширина фиксированная.
    - **Иконки**: все кнопки используют иконки набора Lucide, у большинства есть подпись, у кнопок форматирования — подсказка при наведении.
    - **Цвет акцента** окрашивает выделение текста, курсор, активные кнопки, ссылки в предпросмотре и фокус на кнопках.
    - **Язык интерфейса**: русский или английский, выбирается в «Настройках». Переводятся интерфейс, нативное меню и системные диалоги. Словари лежат в `locales/`.
- **Файловый менеджмент**:
    - Создание нового документа (`Cmd Or Ctrl+N`) — открывается в новой вкладке.
    - Открытие файлов через системный диалог (`Cmd Or Ctrl+O`): `.md`, `.txt`, `.docx` и все файлы. Файл, который уже открыт, переключает на свою вкладку.
    - Сохранение (`Cmd Or Ctrl+S`) и «Сохранить как...» (`Cmd Or Ctrl+Shift+S`).
    - **Экспорт Markdown в HTML**: «Экспорт в HTML…» в боковой панели и меню «Файл» создаёт HTML-страницу в UTF-8 со встроенными светлыми стилями. Экспортируется текущий текст, включая несохранённые изменения; исходный Markdown и его статус сохранения не меняются. Изображения и ссылки сохраняют исходные адреса, без копирования ресурсов; относительные пути могут перестать работать при переносе HTML.
- **Контроль изменений (Unsaved changes)**:
    - Отслеживание состояния каждого документа (`dirty state`).
    - Визуальный индикатор несохранённых правок: `*` рядом с названием во вкладке и в заголовке.
    - Запрос подтверждения только при закрытии вкладки с несохранёнными изменениями.
    - Запрос подтверждения при закрытии окна, если есть несохранённые изменения хотя бы в одной вкладке.
- **Базовый редактор**:
    - Интеграция CodeMirror 6 с подсветкой синтаксиса Markdown.
    - Боковая панель слева: кнопки «Новый», «Открыть», «Сохранить», «Сохранить как», список открытых документов и «Настройки» внизу. Панель сворачивается кнопкой в её верхнем углу или `Ctrl+\`. Когда панель свёрнута, слева остаётся узкая полоска с кнопкой для её открытия. Ширину можно менять перетаскиванием края, двойной клик возвращает ширину по умолчанию (220 px). Состояние и ширина сохраняются между запусками. Также доступно нативное системное меню «Файл» и «Правка».
    - **Импорт `.docx`**: файл открывается в новой вкладке как Markdown-текст (заголовки, списки, жирный и курсив). Исходный файл не меняется, при сохранении предлагается `.md`. Таблицы, картинки и сложные стили не переносятся. Формат `.doc` не поддерживается: приложение попросит сохранить файл как `.docx`.
    - **Вкладки**: несколько документов открыты одновременно. Каждая вкладка хранит свою историю отмены, курсор и режим просмотра. «Новый» (`Ctrl+N`) открывает новую вкладку, повторное открытие уже открытого файла переключает на его вкладку. Закрыть вкладку — `Ctrl+W`, переключение — `Ctrl+Tab` и `Ctrl+Shift+Tab`. Несохранённые изменения спрашиваются только для закрываемой вкладки.
    - **Переименование документа**: двойной клик по вкладке в боковой панели. Для несохранённого документа имя предлагается в окне «Сохранить» и определяет язык и режимы. Для сохранённого файла имя меняется на диске. Если имя задано без расширения, добавляется `.txt`. Символы `\ / : * ? " < > |` недопустимы.
- **Двухпанельный режим для Markdown (Split View)**
    - Разделение рабочей области: панель редактирования исходного текста слева и панель предпросмотра (Live HTML Preview) справа.
    - Синхронизированная прокрутка (Sync Scroll) между редактором и панелью предпросмотра.
    - Возможность переключения режимов отображения (только редактор, split view, только предпросмотр) для `.md` файлов.

- **Панель форматирования текста**
    - Быстрые действия для Markdown через кнопки тулбара и горячие клавиши: заголовки (H1–H6, выпадающий список), жирный, курсив, зачёркнутый текст, списки, цитаты, таблицы, чекбоксы, вставка ссылок и блоков кода.
    - Справа в той же строке находятся кнопки режимов просмотра для `.md` (редактор, разделение экрана, предпросмотр). Без подписей, названия показываются в подсказках при наведении.
    - Горячие клавиши: `Ctrl+B` (жирный), `Ctrl+I` (курсив), `Ctrl+Shift+X` (зачёркнутый), `Ctrl+E` (встроенный код), `Ctrl+K` (ссылка), `Ctrl+Shift+Q` (цитата), `Ctrl+Shift+C` (блок кода), `Ctrl+Alt+1…6` (заголовки). В macOS вместо `Ctrl` используется `Cmd`.

- **Расширенная поддержка языков и кода**
    - Подсветка синтаксиса JS, JSX, TS, TSX, Python, HTML, CSS и JSON для отдельных файлов, а также внутри fenced code blocks в Markdown.
    - Язык определяется по расширению файла. Файлы `.txt` и без расширения открываются без подсветки.

## 3. Архитектура проекта

Структура каталогов и ключевые модули:

```text
├── electron/
│   ├── main.cts             # Electron main (компилируется в dist-electron/electron/main.cjs)
│   └── preload.cts          # Типизированный IPC-мост (компилируется в .cjs)
├── src/
│   ├── App.tsx              # Главный React-компонент (состояние вкладок, режимы, связка с IPC, тулбар и редактор)
│   ├── App.css              # Стили интерфейса (боковая панель, вкладки, тулбар, режимы, диалоги, статусная строка)
│   ├── index.css            # Глобальные стили и CSS-переменные светлой и тёмной тем, цвет акцента
│   ├── main.tsx             # Точка входа React
│   ├── FormatToolbar.tsx    # Панель форматирования Markdown
│   ├── IconButton.tsx       # Общая кнопка с иконкой (react-icons, набор Lucide), подписью и подсказкой
│   ├── Dropdown.tsx         # Собственный выпадающий список с навигацией клавиатурой и цветным образцом
│   ├── Sidebar.tsx          # Боковая панель: файловые действия, список документов, настройки, изменение ширины
│   ├── TabBar.tsx           # Список открытых документов в боковой панели
│   ├── DocumentEditor.tsx  # Редактор одной вкладки на CodeMirror
│   ├── markdownCommands.ts # Команды форматирования и горячие клавиши CodeMirror
│   ├── exportHtml.tsx       # Генерация самостоятельной HTML-страницы из Markdown
│   ├── StatusBar.tsx       # Статусная строка (позиция курсора, счётчики, язык)
│   ├── SettingsDialog.tsx  # Диалог настроек редактора
│   ├── settings.ts         # Типизированные настройки и их сохранение
│   ├── editorTheme.ts      # Тема CodeMirror с цветом акцента
│   ├── languages.ts        # Определение языка по расширению файла
│   ├── types.ts            # Общие интерфейсы renderer
│   └── i18n/               # Переводы и React-контекст (TypeScript)
├── shared/                  # Общий контракт IPC/API для Electron и renderer
├── tsconfig.electron.json   # Типы и сборка Electron-процессов (NodeNext/CommonJS)
├── locales/                 # Словари интерфейса (ru.json, en.json), общие для React и Electron
├── public/            # Статические ресурсы фронтенда
├── dist/              # Директория собранного фронтенда (создаётся после vite build)
├── dist-electron/     # Скомпилированные Electron main/preload (создаётся npm run build)
├── index.html         # Шаблон разметки Vite
├── vite.config.ts     # Типизированная конфигурация сборщика Vite
├── .oxlintrc.json     # Конфигурация линтера Oxlint
└── package.json       # Зависимости и скрипты
```

## 4. Установка и запуск

> [!NOTE]
> В проекте пока не настроена сборка дистрибутивов и инсталляторов (`.exe`, `.dmg`, `.deb` / `electron-builder`), поэтому запуск осуществляется в режиме разработчика/локального выполнения через `npm start`.

### Требования

- Node.js (рекомендуется LTS-версия).
- npm.

### Команды

1. **Установка зависимостей**:

    ```bash
    npm install
    ```

2. **Сборка фронтенда и запуск Electron**:

    ```bash
    npm start
    ```

3. **Сборка статических файлов (Vite)**:

    ```bash
    npm run build
    ```

4. **Проверка качества кода (Linter)**:
    ```bash
    npm run lint
    ```
