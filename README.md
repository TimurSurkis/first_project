# Text Editor

Десктопный текстовый редактор с упором на удобную работу с Markdown, обычным текстом и базовым кодом.

---

## 1. О проекте

Приложение создаётся для комфортного написания заметок, редактирования документов в формате Markdown, работы с plain-text файлами и базового просмотра/редактирования фрагментов исходного кода.

### Основные технологические решения:

- **Electron**: кроссплатформенная десктопная среда.
- **React 19 + Vite**: современный компонентный UI и быстрая сборка.
- **CodeMirror 6** (`@uiw/react-codemirror`): модульное и расширяемое ядро редактора кода и текста.
- **IPC & Context Isolation**: безопасное взаимодействие между процессами Electron (`main`, `preload`, `renderer`).

---

## 2. Текущее состояние и возможности

На данном этапе реализован минимальный жизнеспособный каркас приложения:

- **Базовый UX редактора**
    - **Перенос длинных строк**: включение `EditorView.lineWrapping` в CodeMirror.
    - **Темы оформления**: внедрение светлой и тёмной тем для интерфейса и редактора с возможностью переключения.
    - **Статусная строка**: отображение текущей позиции курсора (Ln, Col), подсчёт символов и слов, индикатор типа файла и кодировки.
    - **Настройки** (кнопка «Настройки»): тема (светлая или тёмная), цвет акцента (синий, зелёный, оранжевый, серо-синий), перенос длинных строк, размер шрифта (12–32 px) и размер табуляции (2, 4 или 8 пробелов). Значения сохраняются между запусками.
    - **Цвет акцента** окрашивает выделение текста, курсор, активные кнопки, ссылки в предпросмотре и фокус на кнопках.
    - **Язык интерфейса**: русский или английский, выбирается в «Настройках». Переводятся интерфейс, нативное меню и системные диалоги. Словари лежат в `locales/`.
- **Файловый менеджмент**:
    - Создание нового документа (`Cmd Or Ctrl+N`).
    - Открытие файлов через системный диалог с фильтрами по `.md`, `.txt` и всем файлам (`Cmd Or Ctrl+O`).
    - Сохранение (`Cmd Or Ctrl+S`) и «Сохранить как...» (`Cmd Or Ctrl+Shift+S`).
- **Контроль изменений (Unsaved changes)**:
    - Отслеживание состояния документа (`dirty state`).
    - Визуальный индикатор несохранённых правок в тулбаре (`*` рядом с названием файла).
    - Предупреждающий диалог перед созданием нового или открытием другого файла.
    - Запрос подтверждения при закрытии окна с несохранёнными изменениями.
- **Базовый редактор**:
    - Интеграция CodeMirror 6 с подсветкой синтаксиса Markdown.
    - Панель инструментов с кнопками: «Новый», «Открыть», «Сохранить», «Сохранить как», «Настройки», а также нативное системное меню «Файл» и «Правка».
    - **Переименование документа**: клик по названию файла в заголовке. Для несохранённого документа имя предлагается в окне «Сохранить» и определяет язык и режимы. Для сохранённого файла имя меняется на диске. Если имя задано без расширения, добавляется `.txt`. Символы `\ / : * ? " < > |` недопустимы.
- **Двухпанельный режим для Markdown (Split View)**
    - Разделение рабочей области: панель редактирования исходного текста слева и панель предпросмотра (Live HTML Preview) справа.
    - Синхронизированная прокрутка (Sync Scroll) между редактором и панелью предпросмотра.
    - Возможность переключения режимов отображения (только редактор, split view, только предпросмотр) для `.md` файлов.

- **Панель форматирования текста**
    - Быстрые действия для Markdown через кнопки тулбара и горячие клавиши: заголовки (H1–H6, выпадающий список), жирный, курсив, зачёркнутый текст, списки, цитаты, таблицы, чекбоксы, вставка ссылок и блоков кода.
    - Горячие клавиши: `Ctrl+B` (жирный), `Ctrl+I` (курсив), `Ctrl+Shift+X` (зачёркнутый), `Ctrl+E` (встроенный код), `Ctrl+K` (ссылка), `Ctrl+Shift+Q` (цитата), `Ctrl+Shift+C` (блок кода), `Ctrl+Alt+1…6` (заголовки). В macOS вместо `Ctrl` используется `Cmd`.

- **Расширенная поддержка языков и кода**
    - Подсветка синтаксиса JS, JSX, TS, TSX, Python, HTML, CSS и JSON для отдельных файлов, а также внутри fenced code blocks в Markdown.
    - Язык определяется по расширению файла. Файлы `.txt` и без расширения открываются без подсветки.

## 3. Архитектура проекта

Структура каталогов и ключевые модули:

```text
├── electron/
│   ├── main.cjs             # Основной процесс Electron (жизненный цикл, меню, IPC-обработчики файлов, отключение аппаратного ускорения)
│   └── preload.cjs          # Скрипт предварительной загрузки (безопасный мост window.api через contextBridge)
├── src/
│   ├── App.jsx              # Главный React-компонент (состояние документа, режимы, связка с IPC, тулбар и редактор)
│   ├── App.css              # Стили интерфейса (тулбар, режимы, диалоги, статусная строка)
│   ├── index.css            # Глобальные стили и CSS-переменные светлой и тёмной тем, цвет акцента
│   ├── main.jsx             # Точка входа React
│   ├── EditableTitle.jsx    # Заголовок с названием файла, редактируемый по клику
│   ├── FormatToolbar.jsx    # Панель форматирования Markdown
│   ├── IconButton.jsx       # Общая кнопка с иконкой (react-icons, набор Lucide), подписью и подсказкой
│   ├── markdownCommands.js  # Команды форматирования и горячие клавиши CodeMirror
│   ├── StatusBar.jsx        # Статусная строка (позиция курсора, счётчики, язык)
│   ├── SettingsDialog.jsx   # Диалог настроек редактора
│   ├── settings.js          # Значения по умолчанию, загрузка и сохранение настроек, списки вариантов
│   ├── editorTheme.js       # Тема CodeMirror с цветом акцента (выделение, курсор)
│   ├── languages.js         # Определение языка по расширению файла и языки для блоков кода
│   └── i18n/                # Перевод интерфейса: словарь translate.js, контекст context.js, провайдер I18nProvider.jsx
├── locales/                 # Словари интерфейса (ru.json, en.json), общие для React и Electron
├── public/            # Статические ресурсы фронтенда
├── dist/              # Директория собранного фронтенда (создаётся после vite build)
├── index.html         # Шаблон разметки Vite
├── vite.config.js     # Конфигурация сборщика Vite
├── .oxlintrc.json     # Конфигурация линтера Oxlint
└── package.json       # Зависимости и скрипты
```

## 4. Установка и запуск

> [!NOTE]
> В проекте пока не настроена сборка дистрибутивов и инсталляторов (`.exe`, `.dmg`, `.deb` / `electron-builder`), поэтому запуск осуществляется в режиме разработчика/локального выполнения через `npm start`.

### Требования

- Node.js (рекомендуется LTS-версия).
- npm.

### Команды

1. **Установка зависимостей**:

    ```bash
    npm install
    ```

2. **Сборка фронтенда и запуск Electron**:

    ```bash
    npm start
    ```

3. **Сборка статических файлов (Vite)**:

    ```bash
    npm run build
    ```

4. **Проверка качества кода (Linter)**:
    ```bash
    npm run lint
    ```
