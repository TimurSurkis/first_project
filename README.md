# Text Editor

Десктопный текстовый редактор на Electron.

## Возможности

- Создание нового документа
- Открытие текстовых файлов (`.txt`, `.md` и любые другие)
- Сохранение и «Сохранить как»
- Предупреждение о несохранённых изменениях при открытии, создании и закрытии

Горячие клавиши: `Ctrl+N`, `Ctrl+O`, `Ctrl+S`, `Ctrl+Shift+S` (на macOS вместо Ctrl используется Cmd).

## Стек

- React + Vite
- CodeMirror 6 (через `@uiw/react-codemirror`)
- Electron

## Запуск

Установка зависимостей:

```bash
npm install
```

Сборка и запуск приложения:

```bash
npm start
```

Только сборка фронтенда:

```bash
npm run build
```
