# Архитектура

Приложение состоит из Electron main-процесса и React renderer-интерфейса, собранного Vite.

## Поток выполнения

1. `electron/main.cjs` создаёт окно Electron и загружает `dist/index.html`.
2. `src/main.jsx` монтирует React-приложение; `src/App.jsx` управляет документами, вкладками, настройками и режимами Markdown.
3. Каждая вкладка отображает отдельный `DocumentEditor` на основе CodeMirror 6. Язык выбирается функцией `findLanguage` в `src/languages.js` по расширению файла.
4. Операции файлов и системные диалоги выполняются в main-процессе. Renderer вызывает только методы, предоставленные через `electron/preload.cjs` и `contextBridge` (`window.api`), используя IPC.

## Основные модули

- `electron/main.cjs` — окно, нативное меню, обработчики IPC, чтение/запись/переименование файлов, импорт DOCX и предупреждение при закрытии окна.
- `electron/preload.cjs` — ограниченный набор вызовов IPC для renderer; изолированный renderer не обращается напрямую к Node.js API.
- `src/App.jsx` — состояние документов и их вкладок, команды меню, просмотр Markdown и синхронизация прокрутки.
- `src/DocumentEditor.jsx` — React-обёртка CodeMirror, тема, перенос строк, фиксация текста и позиции курсора.
- `src/markdownCommands.js` и `src/FormatToolbar.jsx` — команды форматирования и горячие клавиши Markdown.
- `src/settings.js` и `src/SettingsDialog.jsx` — значения параметров и UI настроек. Сохранение настроек производится через `localStorage`.
- `locales/` и `src/i18n/` — словари и React-интеграция переводов; Electron читает те же словари для системного меню и диалогов.

## Модель документов и хранение

Содержимое открытых документов, активная вкладка, курсор и режим просмотра хранятся в состоянии React в течение текущего сеанса. Настройки интерфейса сохраняются в `localStorage` под ключом `editor-settings`. Содержимое документов записывается на диск только при явном сохранении.

Для отслеживания несохранённых изменений renderer сравнивает текущий текст с сохранённым снимком и передаёт признак dirty в main-процесс через IPC. Main-процесс использует этот признак при закрытии окна.

## DOCX

Импорт выполняется в main-процессе с помощью Mammoth (DOCX → HTML) и Turndown (HTML → Markdown). Изображения отбрасываются. Это импорт-конвертация, а не редактирование исходного DOCX.
