# Руководство пользователя

Text Editor — настольное приложение для редактирования Markdown, обычного текста и простых файлов с исходным кодом.

## Работа с документами

- **Новый документ:** нажмите «Новый» в боковой панели или `Ctrl+N` (`Cmd+N` на macOS). Новый документ открывается во вкладке.
- **Открыть:** нажмите «Открыть» или `Ctrl+O` (`Cmd+O`). Поддерживаются `.md`, `.txt` и другие файлы, выбранные через системный диалог. Повторное открытие уже открытого файла переключает на его вкладку.
- **Сохранить:** нажмите «Сохранить» или `Ctrl+S` (`Cmd+S`). Для нового документа приложение предложит выбрать имя и расположение.
- **Сохранить как:** нажмите соответствующую кнопку или `Ctrl+Shift+S` (`Cmd+Shift+S`).
- **Закрыть вкладку:** кнопка закрытия вкладки или `Ctrl+W` (`Cmd+W`). Если документ изменён, приложение попросит подтвердить закрытие.
- **Переименовать:** дважды щёлкните имя документа в списке вкладок слева. Для файла на диске имя меняется и на диске. Если расширение не указано, добавляется `.txt`.

Вкладки и несохранённые документы существуют в текущем сеансе приложения. Документы не сохраняются автоматически. При закрытии окна приложение предупреждает о несохранённых изменениях.

## Markdown

Для файлов `.md` доступны команды форматирования на панели и три режима просмотра:

- **Редактор** — исходный Markdown.
- **Разделённый экран** — исходный текст и предпросмотр рядом; прокрутка синхронизирована.
- **Предпросмотр** — отображённый Markdown.

Панель форматирования включает заголовки H1–H6, жирный и курсивный текст, зачёркивание, списки, чекбоксы, цитаты, ссылки, таблицы и блоки кода. Поддерживается GFM (в частности, таблицы и чек-листы).

### Экспорт в HTML

Для активного документа `.md` нажмите «Экспорт в HTML…» в боковой панели или в меню «Файл», затем выберите путь сохранения. Предлагаемое имя — имя документа с расширением `.html`.

Экспортируется текущий текст, включая несохранённые изменения. Сначала сохранять Markdown не требуется: экспорт не меняет исходный файл, путь вкладки или индикатор несохранённых изменений. При отмене диалога ничего не записывается; перед заменой существующего HTML-файла запрашивается подтверждение.

Результат — HTML-страница в UTF-8 со встроенными светлыми стилями, которую можно открыть в браузере. Тема приложения не влияет на оформление экспорта. Таблицы, чек-листы и блоки кода сохраняются; произвольный HTML из Markdown не исполняется.

Изображения и ссылки сохраняют исходные адреса, ресурсы не копируются и не встраиваются. Относительные пути после переноса HTML в другую папку могут перестать работать. Сетевые изображения требуют подключения к интернету.

## Код и импорт DOCX

Язык файла определяется по расширению. Подсветка есть для JavaScript/JSX, TypeScript/TSX, Python, HTML, CSS и JSON. В Markdown поддерживаются fenced code blocks этих языков. Файлы `.txt` и без поддерживаемого расширения редактируются как обычный текст.

Файл `.docx` можно открыть для преобразования в Markdown. Оригинал не изменяется; результат открывается как новый документ. Изображения удаляются, таблицы и сложное форматирование могут быть преобразованы не полностью. Формат `.doc` не поддерживается.

## Настройки и интерфейс

В «Настройках» можно выбрать русский или английский язык, светлую или тёмную тему, цвет акцента, перенос длинных строк, размер шрифта (12–32 px) и размер табуляции (2, 4 или 8 пробелов). Настройки и состояние/ширина боковой панели сохраняются локально между запусками.

Боковую панель можно свернуть кнопкой в её заголовке или `Ctrl+\` (`Cmd+\` на macOS). Перетаскивайте её правую границу, чтобы изменить ширину; двойной щелчок по границе возвращает ширину по умолчанию.

В строке состояния отображаются позиция курсора, число слов, символов и строк, тип файла и кодировка UTF-8.
