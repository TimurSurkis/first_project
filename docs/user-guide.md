# Руководство пользователя

Text Editor работает в браузере и Electron; документы хранятся на сервере.

## Вход

Создайте аккаунт по email и паролю от 10 символов или войдите в существующий.
Сессия действует 24 часа с момента входа без автоматического продления.
При истечении сессии появится окно повторного входа. Локальный текст остаётся в текущем окне:
войдите тем же аккаунтом и дождитесь сохранения. Не перезагружайте и не закрывайте окно с правками.

## Документы

- **Новый** создаёт облачный Markdown-документ и открывает его во вкладке.
- **Все файлы** показывает сохранённые документы. Выберите «Открыть».
- **Вкладки** — только открытые документы; закрытие вкладки не удаляет файл.
- **Переименование** — двойной клик по вкладке. Если расширения нет, добавится `.txt`.
- **Сохранить** / Ctrl+S запускает сохранение немедленно.
- **Создать копию** / Ctrl+Shift+S создаёт отдельный облачный документ с текущим текстом.
- **Скачать файл** скачивает текущий текст на компьютер.

Изменения автоматически отправляются примерно через 800 мс после окончания ввода.
Вверху показаны статус сохранения и номер версии. Звёздочка у вкладки — несохранённый текст или имя.
При сетевой ошибке нажмите «Повторить»; редактор сначала проверит, не успел ли сервер сохранить текст.
Не закрывайте окно до подтверждения «Сохранено». Незавершённую запись нельзя отменить закрытием вкладки.

Списки файлов загружаются страницами; «Загрузить ещё» показывает следующую.
Одинаковые имена допустимы, так как документы имеют разные ID.

## Корзина

В «Все файлы» нажмите «В корзину». Документ исчезнет из основного списка, но останется на сервере.
Если в открытой вкладке есть локальные правки, приложение запросит подтверждение.
В «Корзине» доступны «Восстановить» и «Удалить навсегда».
Окончательное удаление требует подтверждения и необратимо; автоматической очистки корзины нет.
Документ в корзине нельзя редактировать до восстановления.

## Один документ в двух окнах

Если другое окно успело изменить документ, устаревшая запись не перезапишет его.
Появится конфликт, автосохранение остановится, локальный текст останется в редакторе.

- **Загрузить с сервера** заменяет локальный текст после подтверждения.
- **Создать копию** сохраняет локальный вариант отдельным документом.

Если файл удалён, его можно восстановить через корзину или сохранить локальный текст копией.
Автоматического объединения текстов и истории откатов пока нет.

## Markdown и код

Для `.md` / `.markdown` доступны редактор, split view с синхронной прокруткой и предпросмотр.
Панель форматирования поддерживает заголовки H1–H6, выделение текста, списки, ссылки, цитаты,
таблицы, чекбоксы и код. Подсветка: JS/JSX, TS/TSX, Python, HTML, CSS, JSON.

**Экспорт в HTML…** скачивает самостоятельную UTF-8 страницу со светлыми стилями.
Используется текущий текст, включая несохранённый. Состояние облачного документа не меняется.
Ресурсы не встраиваются; относительные изображения / ссылки не переносятся автоматически.
HTML из Markdown не исполняется.

## Импорт

«Импорт с компьютера…» создаёт новый облачный документ из UTF-8 текста или DOCX.
DOCX преобразуется в Markdown; исходный файл не меняется. Изображения удаляются,
таблицы и сложное форматирование могут терять структуру. Старый DOC не поддерживается.
Файл — до 5 MiB, получившийся текст — до 2 MiB в UTF-8.

## Настройки и ограничения

Язык, тема, цвет акцента, размер шрифта, табуляция, перенос строк и ширина боковой панели
сохраняются локально. Их можно менять через «Настройки».

Нет папок, общего доступа и совместного редактирования. Открытые вкладки после перезапуска
не восстанавливаются, но сохранённые документы остаются в «Все файлы».
Офлайн-черновики пока не записываются на диск / IndexedDB.

См. [горячие клавиши](shortcuts.md); в браузере часть сочетаний может перехватываться самим браузером.
