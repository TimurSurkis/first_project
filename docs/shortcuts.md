# Горячие клавиши

`Ctrl` используется в Windows/Linux; на macOS вместо него используется `Cmd`.

## Файлы и вкладки

| Действие | Windows/Linux | macOS |
|---|---|---|
| Новый документ | `Ctrl+N` | `Cmd+N` |
| Открыть документ | `Ctrl+O` | `Cmd+O` |
| Сохранить | `Ctrl+S` | `Cmd+S` |
| Сохранить как | `Ctrl+Shift+S` | `Cmd+Shift+S` |
| Закрыть активную вкладку | `Ctrl+W` | `Cmd+W` |
| Следующая вкладка | `Ctrl+Tab` | `Cmd+Tab` |
| Предыдущая вкладка | `Ctrl+Shift+Tab` | `Cmd+Shift+Tab` |
| Свернуть/развернуть боковую панель | `Ctrl+\` | `Cmd+\` |

## Форматирование Markdown

Работает в редакторе Markdown. Выделите текст, если нужно применить форматирование к конкретному фрагменту.

| Действие | Сочетание |
|---|---|
| Жирный | `Ctrl/Cmd+B` |
| Курсив | `Ctrl/Cmd+I` |
| Зачёркнутый текст | `Ctrl/Cmd+Shift+X` |
| Встроенный код | `Ctrl/Cmd+E` |
| Вставить ссылку | `Ctrl/Cmd+K` |
| Цитата | `Ctrl/Cmd+Shift+Q` |
| Блок кода | `Ctrl/Cmd+Shift+C` |
| Заголовок H1–H6 | `Ctrl/Cmd+Alt+1…6` |

Списки, чекбоксы, таблицы и другие команды форматирования можно вызвать кнопками на панели.
